# Natural Slabs Mod

Smoothen terrain with natural slabs in Minecraft.

## Features

- Generates natural slabs during elevation or descent
- Custom slab block and item

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Craft natural slabs using stone blocks.
- Place the natural slab blocks to smoothen the terrain.

## Configuration

No additional configuration is required.
